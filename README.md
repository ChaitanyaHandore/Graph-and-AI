# Graph and AI

A project focused on applying graph theory techniques and artificial intelligence to analyze structured relational data using tools like **Neo4j**, **Python**, and **NetworkX**.

## 🚀 Project Overview

This project explores how graph-based data structures can be used to uncover meaningful insights from complex networks. Key concepts include:

- Graph modeling and visualization
- Centrality measures (degree, closeness, betweenness, etc.)
- Network analysis using Python's `NetworkX`
- Graph databases using `Neo4j`
- Real-world applications of graph theory in AI and pattern recognition
